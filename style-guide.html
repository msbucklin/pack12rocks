Cleanup Queue

These are the most visible inconsistencies found in the current Sass. They are ordered by how much polish and maintenance they would buy us.

  • Button variants: Global buttons use consistent 10px corners and 13px type, but Event adds separate dark-blue, pale-blue, green, and amber treatments with different padding and shadows. Consolidate those into shared semantic variants.
  • Button sizing: Most controls use the global 9px by 16px padding, while Event mobile actions grow to 52px and Users & Passwords actions use 55px or 40px at different breakpoints. Define a compact, default, and touch size.
  • Surface hierarchy: Calendar uses the light-blue header gradient, while several Event panels use dark-blue headers and other pages use white-to-pale-blue cards. Choose light blue for data headers and reserve dark blue for navigation or primary actions.
  • Corner radii: The project currently mixes 6px, 8px, 10px, 12px, 14px, 16px, and 18px. A small scale such as 6px controls, 10px cards, and 14px major panels would make the pages feel related.
  • Responsive breakpoints: Most pages use 767px, while Users & Passwords now uses 599px and 1024px for its card grid. Keep page-specific breakpoints where content requires them, but document the shared tablet and phone thresholds.
  • Typography: Montserrat is the shared family, but some navigation labels still force Arial and page headings range from 1.3rem to 2.2rem. Set a small type scale and remove the remaining one-off font override.
